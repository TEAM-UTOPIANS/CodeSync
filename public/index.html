The host holds the signals

Roles are enforced by the room server, not by the page. A viewer who tampers with the browser still cannot change the document.

Roles per person

Switch anyone between editor and viewer while the session runs. It takes effect immediately.

Default for newcomers

Set new joiners to viewer for a lecture or an interview, or to editor for pair programming.

Edit requests

A viewer asks for access. The host allows or denies it with one click.

Lock and passcode

Close the room to newcomers, or require a passcode before anyone can join.

Remove someone

Remove a person for the rest of the session. They cannot rejoin from the same browser.

Hand over the signals

Transfer the host role to another person and step back to editor.

30+ languages, whole projects

Keep several files in one room. Python imports its neighbours, web pages pick up their own CSS and scripts, and C, C++ and Java see their headers and classes. JavaScript, Python and MiniLang run in your browser. The rest are built by public compiler services.

Where each language runs
Code in the first column never leaves your browser. The other columns are sent to a public compiler service to be built and run, so keep secrets out of them.

Everything else in the box

Multi-file projects

Add, rename and delete files. Everyone sees the same tabs.

Follow mode

Click a person to follow their cursor across files.

Shared output

When an editor runs the code, the whole room sees the result.

Checkpoints

Save named versions of the whole project and restore any of them for everyone.

Live web preview

Write HTML, CSS and JavaScript in separate files and watch the page update as you type.

Four themes

Signal Box, Enamel, Night Mail and Locomotive, in the editor too.
